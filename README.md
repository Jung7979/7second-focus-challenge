# 7초 집중력 챌린지

백색소음기 상품을 위한 모바일 30초 프로모션 게임입니다. 개인정보 수집 없이, 선택한 백색소음을 들으며 7초를 맞힌 뒤 예시 혜택과 상품 CTA를 확인합니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 배포 전 별도 설치나 빌드는 필요 없습니다.

## 반드시 바꿀 항목

`index.html`의 `#product-link`에 있는 `href`와 `data-product-url`을 **내 실제 백색소음기 상품 상세 URL**로 바꾸세요. 기본값은 검색 페이지이므로 제출 전에는 반드시 내 상품 페이지를 넣어야 합니다.

브랜드명, 혜택 금액·기간·조건도 실제 판매 정책에 맞게 고치세요. 현재 쿠폰은 화면에도 명시된 **수업용 예시 쿠폰**입니다.

## GitHub Pages 배포

1. GitHub에서 빈 저장소를 만들고 이 저장소에 원격 주소를 연결합니다.
2. `main` 브랜치에 푸시합니다.
3. GitHub 저장소의 **Settings → Pages → Deploy from a branch → main / (root)**를 선택합니다.
4. 생성된 `https://사용자명.github.io/저장소명/` 주소를 제출합니다.

배포 후에는 스마트폰에서 시작, 멈추기, 예시 쿠폰 표기, 상품 보기 버튼을 모두 확인하세요.
