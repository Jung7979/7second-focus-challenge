# 소리쉼표 7초 사운드 비교

층간 생활소음이 신경 쓰이는 사용자를 위한 약 20초 모바일 프로모션 게임입니다. 개인정보 수집 없이 `소리쉼표 OFF`와 `소리쉼표 ON` 환경을 각각 7초 동안 체험하고, 사용자가 직접 더 편하게 느낀 환경을 선택합니다.

## 현재 게임 흐름

1. 빗소리·파도 소리·생활소음 마스킹 노이즈 중 하나를 선택합니다.
2. 소리쉼표 OFF에서 7초라고 느껴질 때 멈춥니다.
3. 소리쉼표 ON에서 같은 방식으로 한 번 더 멈춥니다.
4. 더 편하게 느껴진 환경을 직접 선택합니다.
5. 재미용 7초 기록, 선택 결과, 수업용 예시 혜택을 확인합니다.
6. `소리쉼표 상품 출시 안내`를 누르면 COMING SOON 팝업이 열립니다.

7초 기록은 집중력이나 제품 효과를 판단하는 기준으로 사용하지 않습니다.

## 실행

별도 설치나 빌드 없이 `index.html`을 브라우저에서 열면 됩니다.

## 공개 URL

https://jung7979.github.io/7second-focus-challenge/

## 상품과 혜택 상태

- 소리쉼표 백색소음기는 현재 상품 준비 중입니다.
- 경쟁 상품이나 검색 페이지로 이동하지 않습니다.
- 현재 CTA는 브랜드 디자인의 COMING SOON 팝업을 표시합니다.
- 상품 준비 후 실제 소리쉼표 상품 상세 URL로 교체해야 합니다.
- 3,000원 할인은 **수업용 예시 쿠폰**이며 실제 발급·할인은 제공되지 않습니다.

## 개인정보와 음원

- 입력·로그인·연락처 수집 없이 실행됩니다.
- 기록과 선택은 브라우저 메모리에만 유지되며 저장·전송하지 않습니다.
- 공개 발표와 상업적 운영 전 모든 음원의 사용 권리와 출처를 확인해야 합니다.

## GitHub Pages 배포

1. 최신 변경을 `main` 브랜치에 반영합니다.
2. 저장소의 **Settings → Pages**에서 `Deploy from a branch`를 선택합니다.
3. Branch를 **main / (root)**로 설정합니다.
4. Actions 또는 Pages 화면에서 배포 완료를 확인합니다.
5. 공개 URL을 휴대폰에서 새로 열어 전체 흐름을 확인합니다.

## 발표 전 확인

- 360×640, 375×667 이상의 모바일 화면에서 첫 화면과 멈추기 버튼이 바로 보이는가
- 두 라운드의 소리가 정상 재생되는가
- 타이머가 0.00초부터 증가하고 4초 뒤 숨겨지는가
- OFF/ON 선택 질문과 세 가지 결과 문구가 정상 작동하는가
- 수업용 예시 쿠폰 표기가 명확한가
- COMING SOON 팝업이 열리고 확인 버튼·바깥 영역으로 닫히는가
- 실제 3인 테스트 반응을 제출물에 기록했는가
